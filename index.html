Upload Data (Issue Forma / Luas Survei)

Upload file .zip hasil "Data Export" dari Autodesk Forma/ACC (atau file-file .csv-nya langsung). Data akan otomatis digabung dari issues_issues.csv, issues_issue_types.csv, issues_issue_subtypes.csv, issues_custom_attributes.csv, admin_users.csv, admin_project_users.csv, dan admin_companies.csv — hanya issue dengan Type "Kerusakan Jalan" yang dimuat.

Bisa juga upload satu atau beberapa file CSV titik survei sekaligus (format P;N;E;Z;D) untuk mengisi kolom Luas — luas per kode kerusakan dihitung otomatis dari titik-titik koordinatnya. Tiap file akan ditampilkan satu per satu supaya kamu bisa pilih sendiri file itu punya data luas untuk ruas ROW yang mana.

Soal keamanan: semua proses baca & gabung data terjadi di browser kamu sendiri — file tidak pernah dikirim ke server atau tempat lain manapun. Tapi data yang dimuat cuma nempel di sesi browser ini (hilang kalau halaman di-refresh), dan kalau dashboard ini di-host di repo GitHub publik, siapapun yang buka link-nya bisa lihat isi dashboard yang lagi tampil.

Perhatian: mengirim data ini akan menggantikan seluruh data contoh yang sedang tampil di dashboard.

File CSV titik survei terdeteksi — pilih ruas ROW-nya masing-masing:

File jenis ini tidak menyimpan nama ruas ROW-nya sendiri, jadi pilih atau ketik ruas ROW untuk tiap file di bawah supaya luasnya dicocokkan ke ruas yang benar.
